# Local Model Folder

Download the runtime models described in the main README and place them here.

Expected layout:

```text
models/
  yolov8n.pt
  deploy.prototxt
  res10_300x300_ssd_iter_140000.caffemodel
  face_recognition_sface_2021dec.onnx
  vosk-model/
```

Binary model files are intentionally not generated by the source scaffold. JARVIS logs missing models and keeps the rest of the assistant running.
