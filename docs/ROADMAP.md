# AI Suite Roadmap

This document outlines the strategic vision and upcoming features for AI Suite.

## v0.9.0-alpha
- **✓ Voice System 2.0**: Low latency VAD, cooperative Edge-TTS cancellation.
- **✓ Intelligence Framework**: Ollama integration with SQLite contextual memory.
- **✓ Conversation Polish**: Fixed hallucination bugs and memory constraints.
- **✓ Header Polish**: Professional dynamic metric display.
- **✓ Repository Cleanup**: Release engineering and documentation generation.

## v1.0
- **Installer**: Standalone one-click Windows installer.
- **Settings**: Persistent configuration GUI for profiles, hardware selection, and models.
- **Packaging**: CI/CD pipeline for binary generation.
- **Documentation**: Finalized docs for the initial launch.
- **Public Release**: Open-source GitHub drop.

## v1.1
- **AI Suite Cinematic Boot Sequence**: An immersive, state-of-the-art startup animation visualizing core initializations.
- **Dynamic User Profiles**: Multi-user support with isolated memory databases.
- **Plugin SDK**: Standardized interface for developers to build modular capabilities.
- **First-launch Experience**: An interactive onboarding tutorial workspace.

## v2.0
- **EDITH Security Suite**: Full realization of the third workspace.
- **System Optimizer**: AI-driven OS management and background process tuning.
- **Malware Detection**: Local heuristic-based file scanning.
- **Threat Analysis**: Network packet observation and local anomaly detection.
- **Maintenance Tools**: Automated diagnostic loops.
- **FRIDAY Expansion**: Enhanced multi-agent capabilities and terminal sandboxing for the IDE.
